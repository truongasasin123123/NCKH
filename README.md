# Research Topic Management System – Frontend

Frontend React cho hệ thống quản lý đề tài nghiên cứu khoa học.

## Chạy ứng dụng

```bash
npm install
copy .env.example .env
npm run dev
```

Ứng dụng chạy mặc định tại `http://localhost:5173`.

Đặt URL backend trong `.env`:

```env
VITE_API_URL=http://localhost:3000
```

Build production:

```bash
npm run build
```
